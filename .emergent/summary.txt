<product_requirements>
The Twelvr application is an adaptive learning platform designed for CAT (Common Admission Test) preparation. Its primary objective is to deliver a reliable and personalized learning experience.

**Core Functional Requirements:**
1.  **Adaptive Learning Engine:** The application must feature a robust multi-stage background job pipeline that processes user practice sessions to provide personalized feedback and plan future sessions. The pipeline consists of three stages:
    *   **Summarize:** Analyze session performance and update user mastery models.
    *   **Plan:** Intelligently construct the next practice session pack based on performance gaps.
    *   **Update Insights:** Generate and cache LLM-powered insights for the user's dashboard.
2.  **Session Integrity and Reliability:** User session data must be accurately persisted and resumed. The background job system processing this data must be highly reliable, with mechanisms for monitoring, failure detection, and recovery to ensure the adaptive loop is never broken.
3.  **Dynamic Pre-Session Insights:** Before starting a new session, the user should be presented with a dynamically generated insight card that previews the topics and difficulty of the upcoming questions, powered by an LLM.
4.  **Ask Twelvr Feature:** A context-aware chat modal that allows users to ask questions about the current problem, with conversation history persisted across sessions.
</product_requirements>
