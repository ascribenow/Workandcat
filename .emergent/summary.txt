<product_requirements>
The Twelvr application is an adaptive learning platform designed for CAT preparation. The primary goal is to deliver a reliable, intelligent, and seamless user experience.

**Core Requirements:**
1.  **Production-Grade Infrastructure:** The system must be robust and maintainable. This includes replacing manual operational scripts with a fully agent-executable, API-driven architecture for tasks like data backfills and health monitoring. All operations must be observable and auditable.
2.  **Resilient Adaptive Learning Engine:** The core Adaptive Insights feature must accurately process user learning sessions and generate personalized feedback. This involves ensuring the background job pipeline is reliable and that mastery scores accurately reflect user performance.
3.  **Intelligent User-Facing Features:**
    *   **Dashboard Insights:** The user dashboard must provide specific, actionable, and qualitative insights into their conceptual strengths, weaknesses, and underserved topics, powered by an LLM (Gemini).
    *   **Ask Twelvr Doubts:** The chat feature must be context-aware, referencing the current question and solution. It should provide human-readable responses, especially for mathematical expressions.
    *   **Session Persistence:** User progress within a practice session must be preserved across logins and browser sessions.
</product_requirements>

<key_technical_concepts>
- **Backend:** FastAPI (Python)
- **Frontend:** React.js
- **Database:** PostgreSQL with SQLAlchemy.
- **Asynchronous Tasks:** Background job queue for processing learning sessions.
- **Platform-Native Operations:** Refactoring operational tasks (e.g., data backfills) from manual scripts into internal, agent-callable Admin API endpoints.
- **Observability:** Custom health/monitoring APIs with correlation IDs for end-to-end tracing.
- **LLM Integration:** Using Google Gemini for generating user insights and answering doubts, with a focus on prompt engineering.
