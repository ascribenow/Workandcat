<product_requirements>
The Twelvr application is an adaptive CAT preparation platform leveraging LLMs for personalized question sets. Its core goal was to implement a Blueprint Session System to replace an older polling-based system, ensuring reliable session creation, correct display of post-answer feedback, prevention of auto-advancement, accurate session numbering, synchronized dashboard statistics, robust authentication, and removal of all legacy adaptive learning code.

The immediate future requirement was to implement a **background adaptive intelligence system** for LLM summarization and personalized next-session planning. This system, triggered post-session, must run asynchronously without impacting the real-time frontend. Key specifications included a 2-worker background process, 1-second polling with , exponential backoff for retries, and a lean database schema. The system was refined to have only two job types (, ) and no synchronous LLM fallback on the request path, emphasizing simplicity and non-blocking user experience.
